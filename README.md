# Game Hint Lab

Static English game-guide site. The first guide hub covers **Grow a Chicken Fighter** on Roblox at `/grow-a-chicken-fighter/`.

## Local commands

```text
npm install
npm run dev
npm run build
```

The production build is exported to `out/` and can be deployed as a static site without a database.

## Deployment URL

The production origin is `https://gamehintlab.com`. Set `NEXT_PUBLIC_SITE_URL` if a different preview origin is required before a build; this value drives canonical links, sitemap URLs, robots host and structured-data URLs.

## Evidence policy

- Official Roblox sources support stable game and mechanic claims.
- Codes need official evidence, two current reports, or direct testing.
- Names, prices, odds, effects and requirements need current readable game evidence.
- Rankings require comparable, same-version evidence.
- The umbrella homepage, Grow a Chicken Fighter hub and its codes page are indexable.
- Research routes are `noindex` and excluded from the sitemap.
